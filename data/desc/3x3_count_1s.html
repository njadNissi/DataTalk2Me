3x3_count_1s.csv

Task Overview

3x3_count_1s.csv is a regression task that involves parsing a 3x3 binary matrix (containing only 0s and 1s). For every scenario or row in the dataset, you need to compute the sum of:

  • Row Sums: The total count of 1s present in each of the 3 horizontal rows.
  • Column Sums: The total count of 1s present in each of the 3 vertical columns.
